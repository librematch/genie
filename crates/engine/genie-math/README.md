# genie-math

The arithmetic of build 158041 of Age of Empires II: Definitive Edition as its code does it:
`CVTTSS2SI` conversions, the image's own math routines (`fmath`), angles, the constants the
game's code computes with (`image`, generated) and the map's points, positions and tiles.

genie-model and genie-core compute with it. It depends on no other engine crate (FD-046-D28).
