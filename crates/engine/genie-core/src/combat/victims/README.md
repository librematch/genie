# `combat/victims`: the victims' tests

The tests of a hit's victim (`../victims.rs`): what a unit AI sees of an object, the objects a
blast reaches and the main buildings of the annexes among them, the read where the hit runs,
the write-back of a hit on a live, sleeping, gone or struck object, the order of a strike's
write-backs, and the kill and razings a write-back leaves.
