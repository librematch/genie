# `vision`: what each player sees

Each player sees the tiles in its objects' sight and remembers the tiles it explored. Allies can
share their sight. This folder holds all of it:

- `visibility/` holds the visible maps that the objects' sight keeps.
- `mod.rs` holds the vision masks: which players' sight each player shares.
- `registry.rs` holds the objects-in-sight registry, which the unit AIs search.
- `ghost.rs` holds the fog's ghosts: what a player still sees of an object after it lost sight of
  it.
- `explored.rs` holds the tiles that a player explored in a tick, and the resources it finds there.
- `los_tables.rs` holds the line-of-sight tables. A script generates it.

## How the tick reaches it

An object's sight changes with its move, its master, its death and a building's construction.
After each player's objects, the newly explored tiles give their resources. After the player
loop, the ghosts update and the vision masks are rebuilt.

## In the game

- `RGE_Visible_Map` and `RGE_Unified_Visible_Map` (`visible.cpp`).
- `Visible_Unit_Manager` (`vis_unit.cpp`, `VisibleUnitManager.cpp`).
- `RGE_Doppleganger_Object` (`dpl_obj.cpp`): the ghosts.
