# `objects/facing`: the facets of a master's sprites

The facing (`objects/facing.rs`) turns an object's angle into the facet of its sprite that
shows it. This folder holds the part of it that is the game's data: the facets a master's
sprites have, which the game-data model takes along (FD-046).
