# `orders/gather/retarget`: the Gather's retarget's tests

The tests of the Gather's slot 0x48 on a command's new target (`../retarget.rs`). They cover the
walk to a point without a target, the target the Gather keeps before the building test, its
player's foundation or pasture that the gatherer builds, the building test and the drop test by
an annex's main building, the errors, and what the work command's unit AI hears afterwards.
