# `unit_ai/order_slots`: the order slots' tests

The tests of the unit AI's order slots (`../order_slots.rs`), each called by its own name. The
slots are the defence of an object or a point, the work slots, the gather, the hunt and the
follow. Then come the enter, the transport, the unload, seek and destroy, the explore slots and
the order taken at once. Each slot runs forced and unforced, with and without an action value.
Its target is an object the world holds or one it does not. The tests cover the unit command's
0 and 1, and the last action, target and class that each slot keeps.
