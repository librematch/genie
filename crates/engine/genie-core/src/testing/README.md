# `testing`: the game data genie-core's tests build from

genie-core's tests build their build layer here (FD-046-D08). `build_158041.rs` is build
158041's layer: its roles, slots and tuning values, generated by `harness image layer` from the
build's symbol table (`just layer`). It states the values of `builds/158041.ncl`, each float by
its bits, so a test builds the layer without Nickel; genie-nickel's test `tests/layer.rs` holds
the two equal. The module exists in test builds only.

## Files

| File | What it holds |
| --- | --- |
| [`attribute.rs`](attribute.rs) | The player attributes genie-core's tests name: build 158041's numbers, as the tests' players hold them, by the names the engine's constants had (FD-046-D48: the engine reads them from the build layer's slots and roles). |
| [`build_158041.rs`](build_158041.rs) | Build 158041's layer as genie's tests build it (FD-046-D08): the values of `builds/158041.ncl`, each float by its bits, without Nickel. |
| [`class.rs`](class.rs) | The classes genie-core's tests name: build 158041's `.dat` values, as the tests' masters carry them. |
| [`ids.rs`](ids.rs) | The masters genie-core's tests name: build 158041's `.dat` ids, as the tests' objects carry them, by the names the engine's constants had. |
| [`mod.rs`](mod.rs) | What genie-core's tests build their game data from: each build's layer as the generated fixture states it (FD-046-D08), so a test needs no Nickel, and the classes, masters and player attributes the tests name. |
| [`picker.rs`](picker.rs) | The attack picker of a scene's unit (FD-043-D47): `WorldPicker` over a `World` as the unit AI's view builds it for its unit, the world's spatial index lent beside it, as `bestUnitToAttack`'s field holds both. |
| [`scene.rs`](scene.rs) | A test's world drawn as text (FD-043-D47): the map's tiles, their terrains and elevations, what the scene's player sees of them, the scout and the other objects on it, built into a `World` whose layers agree. |
